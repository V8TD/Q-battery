# Q-battery 0.1

Виджет заряда аккумулятора 1×1 для Android 9 и новее.

- Прозрачный фон, крупные цифры, без знака процента и молнии.
- Один размер цифр для всех значений 0–99, отдельный размер для 100.
- Синий цвет при подключённом зарядном устройстве.
- Обновление по системным событиям + резервная проверка раз в 15 минут.
- Постоянной службы и уведомления нет.
- 5 палитр, редактор цвета: 7 групп × 5 стилей × 15 оттенков.
- Звуковой сигнал при пересечении порога снизу вверх на зарядке.
- Настройки открываются тапом по виджету. Значка в списке приложений нет.

## Сборка через GitHub

1. Загрузить все файлы в репозиторий, сохранив пути.
2. Вкладка **Actions** → сборка запустится сама.
3. Готовый файл: **Artifacts → Q-battery-apk → Q-battery-0.1.apk**.
   Исходники одним архивом: **Q-battery-source**.

## Сборка локально

    gradle --no-daemon assembleDebug

Разрешение в приложении только одно: RECEIVE_BOOT_COMPLETED.
Сторонних библиотек нет.
